# Public CQA candidate repository inventory — 8 November 2026

Companion to the [comparison and implementation priorities](../PUBLIC_HACKATHON_REPOS_2026-11-08.md). This inventory covers 52 public repositories matching the same Freedom CQA case, not 52 verified teams or official accepted submissions. It includes older/alternate versions. Search is not exhaustive; private repositories and non-default branches were not audited.

**Evidence:** C = selected implementation files were read, with fetched blobs matching the public tree; R = README/default tree screening only. C does not mean all code was audited or any application/test was executed. R statements describe the published approach and visible structure, not proven runtime behavior. No claimed pass count, price, quality percentage, deployment or human-label provenance was independently reproduced. References are direct primary repository links.

Most entries share the same mandatory checklist/evaluation/evidence/appeal workflow already implemented in our application. The final column identifies incremental ideas or says when no distinct advantage was established. It does not imply we lack the common workflow.
